# AI 서버 출력 형식: 회의 중 요약 (ai-service → 백엔드) v0.1 초안

> 회의 중 주기 요약을 백엔드로 돌려주는 방식만 다룬다. 입력 형식은 `input-contract.md`에 있다.
> 안건 보드, 오늘 회의 요약, 회의록 초안은 백엔드와 합의된 API 초안(연동 API 초안 7장 답변)을 따르며 이 문서의 범위 밖이다.

## 1. 목적과 범위

| 구분 | 내용 |
|---|---|
| 목적 | 회의 중 만들어지는 요약을 ai-service가 백엔드로 보내는 방식을 정한다 |
| 방식 | ai-service가 백엔드로 `PUT`으로 밀어 준다 (안건 보드와 같은 방식, 백엔드 제안) |
| 이 문서 밖 | 안건 보드, 오늘 회의 요약, 회의록 초안, 챗봇 |

## 2. 보내는 방식

| 항목 | 내용 |
|---|---|
| 주소 | `PUT {백엔드 주소}/internal/meetings/{meetingId}/live-summary` (뒷부분은 AI 제안, 백엔드가 바꾸면 환경변수 `LIVE_SUMMARY_PATH`만 고친다) |
| 보내는 때 | 요약 내용이 바뀐 직후. 바뀌지 않으면 보내지 않는다 |
| 마지막 | 회의 `end` 알림을 처리한 뒤 `final`이 `true`인 요약을 한 번 보낸다. 내용이 같아도 보낸다 |
| 보내는 주기 | 요약은 약 1분 주기로 갱신하므로 보내는 횟수도 그 정도이다 |
| 설정 | 백엔드 주소는 환경변수 `BACKEND_BASE_URL`. 비어 있으면 보내지 않는다 |

## 3. 본문

| 필드 | 타입 | 설명 |
|---|---|---|
| `schemaVersion` | 문자열 | 요약 저장 형식 버전. 지금은 `"0.1"` |
| `meetingId` | 문자열 | |
| `version` | 정수 | 요약의 번호. 4장 규칙 |
| `atMs` | 정수 | 이 요약이 만들어진 시점의 음성 시각 |
| `final` | 불리언 | 회의가 끝난 뒤의 마지막 요약이면 `true` |
| `summary` | 배열 | 요약 항목. 항목은 아래 표 |

### 3.1 summary의 항목

| 필드 | 타입 | 설명 |
|---|---|---|
| `text` | 문자열 | 요약 한 줄 |
| `topic` | 문자열 또는 null | 짧은 주제 이름 |
| `evidence` | 배열 | 근거가 된 전사 구간. `{"start": 초, "end": 초}` (음성 시각, 초 단위 실수) |

요약 저장 형식 v0.1의 `summary[]`와 같다. 이 단계에서는 결정 사항과 할 일을 만들지 않으므로 `decisions`, `action_items`는 보내지 않는다.

## 4. version 규칙

- 같은 회의에서 보낼 때마다 커진다.
- 시각(밀리초) 이상의 값으로 시작해서, ai-service가 재시작해도 이전에 보낸 값보다 작아지지 않는다.
- 백엔드는 이미 받은 값보다 작거나 같은 `version`을 버린다. (순서가 뒤섞여 도착해도 최신이 남는다)

## 5. 응답과 재시도

| 백엔드 응답 | ai-service의 동작 |
|---|---|
| `2xx` | 성공 |
| `408`, `429`, `5xx`, 연결 오류 | 재시도 3회, 간격 1초·2초·4초 (지수 백오프) |
| 그 밖의 `4xx` | 다시 보내도 소용없으므로 포기하고 로그에 남긴다 |

- 재시도하는 사이에 같은 회의의 더 새 요약이 생기면 옛것은 다시 보내지 않고 새것을 보낸다. 회의마다 가장 최신 하나만 남긴다.
- 모두 실패해도 다음 요약이 만들어질 때 다시 보낸다.

## 7. 협의 상태

| 항목 | 상태 |
|---|---|
| 회의 중 요약은 ai-service가 `PUT`으로 밀어 준다 | 백엔드 제안 (2026-10-20), AI 동의 |
| 주소의 뒷부분(`live-summary`) | AI 제안, 백엔드 확인 필요 |
| 본문 필드와 타입 | AI 제안, 백엔드 확인 필요 |
| `version`을 시각(밀리초) 이상으로 시작 | AI 제안, 백엔드 확인 필요 (재시작 시 낮은 번호를 버리는 문제 때문) |
| 재시도 3회, 지수 백오프 | 연동 API 초안 7장 6번 합의 내용을 따름 |
