# 안건별 요약 평가 결과 v1 (AI-03)

> 회의 1건, 모델 1종, 1회 실행. 베타 전 참고용이며 표본이 작아 통과·미달을 단정하지 않는다.
> 이 문서에는 전사 내용과 요약 문장을 넣지 않는다 (줄 번호, 문장 번호, 수치만).

## 1. 한 줄 결과

자동으로 잰 기준은 모두 넘었지만 지표가 후해서 합격이라고 보지 않는다. 사람이 읽고 매긴 사전 채점에서는 지어낸 사실은 없었으나 의미가 달라진 문장이 10개 중 2개(20%)로, 제안 기준(10% 이하)에 못 미쳤다.
프롬프트와 기준은 고치지 않고 그대로 기록하며, 베타에서 새 회의로 다시 잰다.

## 2. 평가 방법

| 항목 | 내용 |
|---|---|
| 데이터 | AI-02 평가와 같은 회의 1건 (전사 256줄 중 분류 대상 182줄), 평가용 안건 4개, 확정 분류 라벨 |
| 핵심 내용 체크리스트 | 안건별로 요약에 담겨야 할 내용 13개 (담당 분야 3 / 지라 5 / 비용 3 / 마무리 2). Claude가 초안을 만들고 담당자가 확정했다. 항목마다 정답 근거 줄 번호가 있다 |
| 재생 | 실제 서비스처럼 10초 묶음으로 보내고, 요약기를 묶음마다 돌린 뒤 종료 때 한 번 더 돌린다 |
| 변형 | `gold`: 사람이 확정한 분류를 그대로 사용 (요약기 자체 품질). `ai`: AI-02 분류기 결과를 사용 (분류 오류를 얼마나 물려받는지) |
| 모델 | gemini-3.8-flash |
| 도구 | `summary/eval_agenda_summary.py` (유료 호출은 `--paid-ok` 필요, 결과 파일이 있으면 거부) |
| 채점 | 자동: 근거 정확도, 핵심 내용 포함(근거 줄 겹침으로 근사), 문장 수. 사람 확인: 문장이 근거 줄로 뒷받침되는지, 의미가 달라졌는지 |

## 3. 기준과 결과

| 기준 | 제안 기준 | gold | ai | 비고 |
|---|---|---|---|---|
| 근거 정확도 (근거 줄이 그 안건의 정답 줄인 비율) | 90% 이상 | 100% (59/59) | 70.4% (57/81) | ai는 분류 오류의 영향이라 참고용 |
| 핵심 내용 포함 (근거 겹침 근사) | 70% 이상 | 13/13 | 13/13 | 변별력 낮음 (4장) |
| 안건당 문장 수 | 3개 이하 | 최대 3 | 최대 3 | |
| 문장이 근거로 뒷받침됨 (사전 채점) | 90% 이상 | 10/10 | 미채점 | |
| 의미가 달라진 문장 (사전 채점) | 10% 이하 | 2/10 (20%) | 미채점 | 기준 미달 |
| 검증기 경고가 붙은 문장 | 기준 없음 | 7/10 | 8/9 | 경고 내용은 기록하지 않아 원인 미확인 |

## 4. 자동 지표가 후한 이유

- gold에서 안건당 문장 3개가 그 안건 줄 거의 전부를 근거로 걸었다 (담당 분야 19줄 중 18줄, 지라 28줄 전부, 비용 10줄 전부). 근거가 넓으면 어떤 핵심 내용과도 겹치므로 "포함 13/13"은 변별력이 거의 없다.
- 문장당 평균 근거 줄 수는 gold 5.9, ai 9.0이다.
- 그래서 핵심 내용 포함은 사람 채점을 함께 봐야 한다. 사전 채점에서는 13개 중 12개가 담겼고 1개(이전에 쓰기로 이야기가 됐었다는 부분)가 절반만 담겼다.

## 5. 사전 채점 (gold, 문장 10개)

채점은 Claude가 초안으로 매겼고 담당자가 이의 없이 그대로 확정했다. 같은 사람 한 명의 확인이라 두 사람 일치도는 재지 못했다.

| 구분 | 결과 |
|---|---|
| 근거 줄로 뒷받침됨 | 10/10. 근거에 없는 사실을 지어낸 문장은 없었다 |
| 의미가 달라진 문장 | 2개. 이미 하고 있다는 말을 제안으로 바꾼 문장 1개 (지라 안건), 설명을 질문으로 바꾸고 원문에 없는 단위를 붙인 문장 1개 (비용 안건) |
| 사소한 해석이 섞인 문장 | 3개. 두 말을 합치거나 인과 연결을 더한 것으로, 의미가 달라진 정도는 아니라고 판단했다 |

## 6. 분류 오류가 요약으로 넘어옴 (ai)

- 근거 81줄 중 24줄이 정답으로는 그 안건의 줄이 아니다. 근거에 다른 안건 줄이 섞인 문장이 4개다 (담당 분야 안건 2개, 지라 안건 2개).
- 담당 분야 안건의 한 문장은 진로·채용 잡담을 요약했고, 지라 안건에는 공고 우대사항 언급이 섞였다.
- AI-02 평가에서 본 "잡담이 안건 1로 새는" 오류가 요약까지 이어진다. 원인은 요약기가 아니라 분류이므로 AI-02 개선이나 사람의 분류 수정으로 푼다.

## 7. 지연과 비용

| 항목 | gold | ai |
|---|---|---|
| 요약 호출 | 27회 | 24회 |
| 분류 호출 | 없음 (사람 분류 사용) | 59회 |
| 재생 전체 시간 | 362초 | 568초 |
| 추정 비용 | 약 187원 | 요약 약 189원 + 분류 약 200원 |

- 총 추정 비용은 약 576원이다 (토큰 수와 환율 1,400원은 가정이라 실제와 다를 수 있다).
- 호출 한 번에 약 11~13초가 걸렸다 (재생 시간을 호출 수로 나눈 대략값). 분류 주기 30초에 요약 시간을 더하면 갱신 지연 1분 이내 목표에 빠듯하다. 실제 연동에서 다시 잰다.

## 8. 한계와 다음

- 회의 1건, 정답 분류와 체크리스트와 채점을 모두 한 사람이 확정했다. 수치는 참고용이다.
- 체크리스트 초안과 사전 채점을 Claude가 만들었다. 평가 대상 모델(Gemini)과는 다른 계열이지만 편향 가능성은 있다.
- 같은 데이터로 프롬프트를 고쳐 다시 재면 점수가 부풀려지므로 이번 결과를 보고 고치지 않았다.
- 읽기 부담: 문장이 길고 받아쓰기가 깨진 부분을 「인용」과 "(STT 불확실)"로 반복해 적어서, 화면만 보고 따라잡는다는 목적에는 무겁다.
- 줄이 적은 안건은 문장이 1개만 나온다 (줄 수 ÷ 3 올림, 최대 3개).
- 고친 문장은 근거 줄이 바뀌거나 옮겨 갔을 때만 확인 필요를 켠다. 이후 발언의 의미가 달라지는 경우는 감지하지 않는다.
- 이 평가는 요약 문장 단위만 쟀다. 사람이 고친 문장의 잠금과 확인 필요는 자체 시험(실수 주입 24건 포함)으로 확인했고 이 평가에는 포함하지 않았다.
- 다음 개선 후보 (구현하지 않음): 근거 구간 길이 제한, 인용 줄이기, 경고 개수와 종류를 전사 내용 없이 기록, 문장 길이 제한. 베타에서 새 회의로 효과를 재고 정한다.
