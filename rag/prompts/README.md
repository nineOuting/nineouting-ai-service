# rag/prompts

LLM 에 보내는 지시문(시스템 프롬프트)을 모아 둔다. 종류마다 폴더 하나, **버전마다 파일 하나**다.
이미 있는 버전 파일은 고치지 않고, 새 버전은 새 파일로 만든다. 그래서 설정의 버전만 바꾸면 지시문을 갈아끼우거나 되돌릴 수 있다.

| 폴더 | 쓰는 곳 | 고르는 설정 | 코드가 꼭 필요로 하는 글 |
|---|---|---|---|
| `answer/` | 답변 API (`rag/answer.py`) | `RAG_ANSWER_PROMPT_VERSION` (예: `v1`). 없으면 번호가 가장 큰 파일 | `NO_ANSWER` (근거로 답할 수 없을 때 LLM 이 내는 표시. 코드가 이 글로 no_result 를 판정한다) |

## 형식

`answer/v2.md`:

```markdown
---
version: answer-v2
---
지시문 본문
```

- 파일 이름은 `v1.md`, `v2.md` 처럼 `v` + 번호. 맨 위 `---` 사이의 `version` 은 `종류-파일이름` (`answer-v2`) 이어야 한다 (다르면 그 기능만 503)
- 서버 로그에 질문마다 `prompt=answer-v2` 처럼 남아, 어느 지시문으로 만든 답인지 알 수 있다
- 본문은 앞뒤 빈 줄을 빼고 그대로 LLM 에 보낸다

## 고칠 때

1. 가장 큰 번호의 파일을 복사해 다음 번호로 만들고(`v2.md` → `v3.md`), 머리의 `version` 을 맞춘 뒤 새 파일만 고친다. 아래 "변경 기록"에 한 줄 적는다
   - 합치면 설정이 없는 서버는 새 버전을 쓴다. 문제가 생기면 `RAG_ANSWER_PROMPT_VERSION=v2` 로 이전 버전으로 되돌린다
2. 위 표의 "꼭 필요로 하는 글"을 지우지 않는다. 빠지면 서버는 뜨지만 그 기능만 503 이 된다
3. 서버를 다시 띄워야 반영된다 (시작할 때 한 번 읽는다)
4. `.venv/bin/python -m rag.try_answer` 로 같은 질문을 해 보고, 근거 번호와 NO_ANSWER 규칙을 지키는지 본다

### 버전을 올리는 기준

| 경우 | 버전 |
|---|---|
| 본문을 바꿈 (오타·띄어쓰기만 고쳐도) | 새 파일을 만든다. AI 에 들어가는 글이 바뀌면 답이 달라질 수 있다 |
| PR 을 합치기 전에 로컬에서 여러 번 고쳐 보며 시험 | 그 PR 의 새 파일 하나를 계속 고친다. 합친 뒤에는 그 파일도 고치지 않는다 |
| 여러 안을 비교 | 안마다 번호를 따로 주고(`v3.md`, `v4.md`), `RAG_ANSWER_PROMPT_VERSION` 으로 바꿔 가며 같은 질문을 해 본다. 고르지 않은 안은 합치기 전에 지운다 |

## 변경 기록

| 버전 | 날짜 | 바꾼 것 | 이유 |
|---|---|---|---|
| answer-v1 | 2026-10-21 | 처음 (근거만으로 답, 문장마다 번호, NO_ANSWER, 자료 속 지시 무시) | – |
| answer-v2 | 2026-10-21 | 번호는 자료에 붙은 것 중에서만 고르고 없는 번호를 만들지 않는다고 분명히 함. 한 문장의 근거가 여럿이거나 여러 회의에 걸치면 모두 붙이게 함. 자료가 일부만 답하면 그 범위에서 답하고(어느 회의 기준인지, 없는 부분은 없다고), NO_ANSWER 는 자료가 전혀 관계없을 때만 | 실제 Gemini 시험에서 근거가 1개만 나오는 경우가 있었고, "지금 어디까지 진행되었어?" 처럼 넓은 질문에 흩어진 조각만 와서 NO_ANSWER 로 끝남 |
| answer-v3 | 2026-10-30 | 답할 내용이 하나도 없으면 "자료에 없다" 문장도 쓰지 말고 NO_ANSWER 만. 낱말·사람 이름만 오면 그에 관한 내용을 정리(사람이면 맡은 일을 항목마다). 합니다체 | 실제 OpenAI(gpt-5.6-luna) 시험에서 "디자인팀은 몇 명이야?"에 "자료에 디자인팀 인원은 나와 있지 않습니다."를 씀. 회의록 아카이브 검색 칸에는 낱말만 넣는 경우가 많음. 답마다 "~했다"·"~습니다"가 섞임 |

자료·질문 칸(`<자료>`, `<질문>`)은 코드(`answer.build_prompt`)가 만든다. 조각 글 안의 꺾쇠를 바꿔 칸 밖으로 새지 않게 하는 처리가 함께 있어서 파일로 빼지 않았다.
